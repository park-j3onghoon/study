# 실습 2: 커스텀 Skill 만들기

## 목표
YAML frontmatter + Markdown 구조의 SKILL.md를 직접 작성해본다.

## 시나리오
팀에서 자주 쓰는 "코드 리뷰" 워크플로우를 스킬로 만들려 합니다.

## 요구사항

1. **이름**: `review`
2. **설명**: "PR 코드 리뷰를 수행한다"
3. **사용자가 직접 호출** 가능해야 함 (`/review`로)
4. **자동 발동은 비활성화** (Claude가 알아서 발동하지 않게)
5. **본문**에 리뷰 절차 3단계를 작성:
   - 변경 파일 목록 확인
   - 각 파일의 diff 분석
   - 리뷰 코멘트 작성

## 할 일
