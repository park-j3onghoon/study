# 실습 01: 권한/범위 구분 (기본)

목표: 아래 3개를 명확히 구분한다.
- 세션 권한(승인 정책)
- 디렉터리 접근 범위
- 프로필(재사용 가능한 기본 설정)

## 1) 명령 실행
```bash
codex --help | rg -n "ask-for-approval|sandbox|add-dir|profile|full-auto"
```

## 2) 출력 보고 (직접 작성)
아래 문장을 채운다.
- 세션 권한 설정 옵션은 `_____` 이다.
- 디렉터리 확장 옵션은 `--add-dir` 이다.
- 기본 설정 재사용 옵션은 `--profile` 이다.

## 완료 조건
- 위 3문장을 정확히 채우고, 채팅에 붙여넣기
