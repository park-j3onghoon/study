# 세션 종료 처리 규칙

모든 사이클이 끝나면 아래를 순서대로 수행한다.

## 1. 학습 세션 요약 리포트

이번 세션의 모든 변경사항을 정리해서 보여준다:

```
━━━ 세션 요약 ━━━
날짜: {YYYY-MM-DD}
학습 주제: {대주제} > {소주제}
사이클: {N}회 수행

[개념 설명]
- {설명한 개념 요약}

[실습]
- {수행한 실습 요약}

[퀴즈 결과]
- 총 {맞은 수}/{전체 수} ({정답률}%)
- 틀린 문제: {요약}

[커버리지]
- 실습: {X}% / 퀴즈: {X}% / 총: {X}%

[파일 변경사항]
- 생성: {새로 만든 파일 목록}
- 수정: {수정한 파일 목록}
  - {파일명}: {무엇을 바꿨는지 한 줄 설명}

[설정 변경사항]
- {settings.json, SKILL.md 등 변경 내용}

[권한 변경사항]
- {추가/수정된 권한이 있으면 표시}
```

## 4. 커밋 & 푸시

1. 변경된 파일들을 `git add` (학습 자료, 로그, 설정 등)
2. 커밋 메시지: `study: {대주제}/{소주제} - 사이클 {N}회 ({정답률}%)`
3. `git push`까지 수행
