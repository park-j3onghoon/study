# 학습 로그 규칙

## 기록 위치

`~/git/study/log/history.md`에 누적 기록한다.

## 기록 형식

```markdown
## {YYYY-MM-DD} | {대주제} > {소주제}

- 학습 내용: {한 줄 요약}
- 퀴즈 결과: {맞은 수}/4 ({틀린 난이도 표시})
- 커버리지: 실습 {X}% / 퀴즈 {X}% / 총 {X}% (누적 {N}사이클)
- 틀린 문제:
  - Q{번호} [{난이도}]: {문제 요약} → 오답: {선택한 답} / 정답: {올바른 답}
  - 오답 원인: {왜 틀렸는지 분석}
- 남은 영역: {다루지 못한 세부 주제들}
- 질문/혼란: {학습 중 사용자가 질문하거나 헷갈려한 부분}
- 약점 태그: #{태그1} #{태그2}
```

## 약점 태그 목록

- `#용어혼동` — 비슷한 개념을 혼동
- `#실행순서` — 코드 실행 흐름을 잘못 예측
- `#엣지케이스` — 경계 조건을 놓침
- `#문법` — 문법/신택스 실수
- `#개념누락` — 핵심 개념을 아예 모름
- `#응용부족` — 개념은 알지만 적용을 못함
- (새 패턴 발견 시 추가)

## 활용

- 같은 주제 재학습 → 이전에 틀린 부분 집중 보충
- 다른 주제 학습 → 약점 태그 패턴으로 설명 방식 조절
- `#실행순서` 많으면 → 도식/플로우차트 더 상세히
- `#용어혼동` 많으면 → 비교표 추가 제공
