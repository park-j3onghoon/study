# 교차 약점 분석 규칙

주제가 달라도 같은 유형의 실수가 반복될 수 있다. 이를 추적하고 보완한다.

## weakness.md 관리

`~/git/study/log/weakness.md`에 교차 약점 프로필을 관리한다.

매 학습 세션 종료 후:
1. 이번 세션의 약점 태그를 weakness.md의 기존 데이터와 대조
2. 같은 태그가 **2개 이상 서로 다른 주제**에서 반복 → 교차 약점 등록
3. 기존 패턴 강화 시 weakness.md 업데이트

## weakness.md 형식

```markdown
# 교차 약점 프로필

최종 업데이트: {YYYY-MM-DD}

## 활성 약점

### #실행순서 (출현 3회)
- 발견 주제: git/rebase, python/decorators, docker/build
- 패턴: 순차 과정에서 순서 혼동
- 보완 전략: 플로우차트 필수, 순서 배열 문제 포함

## 해소된 약점

### #문법 (출현 2회 → 최근 3회 연속 정답)
- 해소 일자: {YYYY-MM-DD}
```

## 보완 전략 자동 적용

활성 약점은 모든 학습 세션에서 자동 적용:

| 약점 | Explain | Execute | Quiz |
|------|---------|---------|------|
| `#실행순서` | 번호 매긴 플로우차트 필수 | 실행 순서 예측 후 확인 | 순서 배열 문제 |
| `#용어혼동` | 유사 개념 비교표 필수 | 두 개념 나란히 실행 | 용어 구분 함정 |
| `#엣지케이스` | 경계 조건 별도 섹션 | 경계값 테스트 실습 | 엣지케이스 시나리오 |
| `#개념누락` | 사전 지식 섹션 추가 | 기초부터 단계별 | [하] 2개로 확대 |
| `#응용부족` | 실전 사례 추가 | 실무 시나리오 실습 | [상][최상] 실무 맥락 강화 |
| `#문법` | 문법 규칙 요약 박스 | 의도적 오류 수정 | 문법 오류 찾기 |

## 약점 해소 조건

- 해당 태그 유형 문제 **3회 연속 정답** → "해소된 약점"으로 이동
- 해소 후에도 가끔 확인 문제 출제 (퇴행 방지)

## 스킬 자체 업데이트

위 표에 없는 새로운 약점 패턴 발견 시:
1. weakness.md에 새 약점과 보완 전략 기록
2. 이 파일의 보완 전략 표에 새 행 추가
