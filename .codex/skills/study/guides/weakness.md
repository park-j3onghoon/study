# 교차 약점 분석 규칙 v2 (Codex)

주제가 달라도 같은 유형의 실수가 반복될 수 있다. v2는 도메인 prefix·자신감 약점·다음 주제 추천을 포함한다.

## weakness.md 관리

`~/git/study/log/weakness.md`에 교차 약점 프로필 유지. Codex는 사용자가 종료 처리 요청한 경우에만 갱신.

매 학습 세션 종료 후:
1. 이번 세션의 약점 태그를 weakness.md의 기존 데이터와 대조
2. 같은 태그가 **2개 이상 서로 다른 주제**에서 반복 → 교차 약점 등록
3. `#meta/*` 태그는 같은 주제 내 누적도 인정 (자신감 추이는 주제 무관)
4. 기존 패턴 강화 시 weakness.md 갱신

## weakness.md 형식

```markdown
# 교차 약점 프로필

최종 업데이트: {YYYY-MM-DD}

## 활성 약점

### #tech/용어혼동 (출현 3회, 가중치 1.0)
- 발견 주제: claude-code/basics, claude-code/rules-vs-skills, ai-ml/...
- 패턴: 비슷한 이름·역할 개념 혼동
- 보완 전략: 유사 개념 비교표 필수, 용어 구분 함정 문제 포함
- 해소 카운트: 1/3 (Bloom L3 이상 필요)

### #meta/과신 (출현 4회, 가중치 0.8)
- 추이: 자신감 예측이 실제 정답률보다 평균 +0.22 높음
- 보완 전략: Quiz 시작 시 자신감 예측 강제 + 종료 비교 노출 강조
- 해소 조건: 최근 3회 confidence delta 평균 ±10% 이내

## 해소된 약점

### #tech/문법 (출현 2회 → 최근 3회 연속 정답 + Bloom L3 이상)
- 해소 일자: {YYYY-MM-DD}
```

## 도메인 가중치 & 해소 조건

상세: `guides/schema-v2.md` §3 참조.

- 가중치: tech 1.0, design 1.2, soft 1.2, meta 0.8
- 일반 해소: 3회 연속 정답 + Bloom 동일 이상 레벨
- `#meta/과신|저신`: 최근 3회 confidence delta 평균 ±10% 이내가 3회 연속
- `#meta/일관성결여`: 같은 개념 3회 동일 정답률(±10%) 통과

## 다음 주제 추천 알고리즘

세션 종료 시 자동 계산하여 history.md와 사용자 리포트에 출력.

```
score(concept) = 
  Σ (도메인가중치 × 미해소 약점 출현 횟수)        # 약점 보충 점수
  + max(0, 오늘 - next_due) × 0.1                  # FSRS 만기 페널티
  + 선행 개념 의존성 점수                            # prerequisites 채워진 정도
```

상위 3개를 "추천 다음 주제"로 출력. 사용자가 다음 세션 시작 시 자유롭게 선택.
